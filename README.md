# nuriv Jar Studio

โปรแกรมกระปุก 3D ของ nuriv (13 สินค้า ใช้กระปุกเดียวกัน เปลี่ยนฉลาก): ปรับมุม ใส่คลิป/รูปเป็นฉากหลัง
แล้ว Export เป็น PNG, MP4 หรือ PNG ทีละเฟรม

## วิธีใช้
- เปิด `index.html` ด้วย **Google Chrome** หรือ **Microsoft Edge** (ต้องต่ออินเทอร์เน็ต)
  โฟลเดอร์ `labels` ต้องอยู่ข้าง `index.html` เสมอ (เก็บฉลากของแต่ละสินค้า)
- เลือกสินค้าที่ช่อง "สินค้า" ด้านบนของแผงควบคุม
- ลาก = หมุน/เอียง · Shift+ลาก = เลื่อน · ล้อเมาส์ = ซูม · ดับเบิลคลิก = รีเซ็ต
- ไฟล์ที่ Export จะอยู่ในโฟลเดอร์ Downloads
